🗳️ Election Assistant AI

A modern AI-powered platform designed to educate, guide, and empower voters through the election process using intelligent tools and real-time insights.

🔗 Live App:
👉 https://election-assistant-986739001278.europe-west1.run.app/

🚀 Features
🤖 AI Chatbot Assistant
Powered by advanced AI (e.g., Gemini API)
Answers election-related queries instantly
Provides neutral, fact-based guidance
📰 Fake News Detector
Identifies misinformation related to elections
Helps users verify viral claims and news
Important due to rising election disinformation risks
📊 Voting Readiness Score
Personalized readiness analysis
Checks awareness, registration, and preparedness
Encourages informed participation
🗳️ Why Your Vote Matters (Simulation Engine)
Interactive simulation showing impact of voting
Demonstrates how individual votes influence outcomes
📅 Smart Voting Day Planner
Guides users with timelines (registration → voting day)
Helps plan voting efficiently
Reduces confusion around election processes
📍 (Optional/Extended) Polling Info & Guidance
Helps users understand voting steps
Inspired by real election assistant tools providing polling details
🛠️ Tech Stack
Frontend: React.js
Backend: Node.js / Express
AI Integration: Google Gemini API
Database: Firebase / Firestore
Authentication: Firebase Auth
Hosting: Google Cloud Run
